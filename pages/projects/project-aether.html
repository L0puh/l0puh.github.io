// project description
a compact Type-1 hypervisor for STM32F103C6T6 (Blue Pill).
provides MPU-based task isolation without an MMU —
the only hardware isolation mechanism available on Cortex-M3.

$ cat features.txt | head -30

// core features
- MPU-based isolation
    * per-app MPU configuration before each launch
    * apps restricted to own Flash slot, RAM region, HV API table
    * background mode blocks all unprivileged access after return
- secure app loading
    * apps delivered over UART as signed binaries
    * signature verification before any Flash write
    * untrusted code never reaches executable memory
- hypervisor API
    * fixed-address function table at 0x20002400
    * caller validation
    * controlled access to MCU
- application model
    * apps described by app_desc_t (magic + entry point)
    * bootloader scans slots sequentially, no OS needed
    * dynamic loading without reflashing the bootloader
